# Mein Portfolio / Lebenslauf

Dies ist meine persönliche Portfolio- und Lebenslauf-Webseite, die ich erstellt habe. Sie präsentiert meine Fähigkeiten, Kenntnisse und Kontaktdaten.

## Verwendete Technologien

* **HTML** für die Struktur der Webseite
* **CSS** für das Design und Styling 

##  Projektstruktur

* `index.html` - Die Hauptseite mit meinen persönlichen Daten und Fähigkeiten.
* `css/` - Der Ordner, der die Stylesheet-Dateien für das Design enthält.
